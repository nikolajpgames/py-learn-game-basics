The DVD Bouncer

Your box already moves. Today you teach it to notice the walls — and to turn round when it finds one.

What you're making

The old DVD player screensaver, more or less. Yours will be doing this by the end of the session.

New this session

if asks the computer a question, and only runs the lines underneath when the answer is yes. That's the whole thing. There isn't more to it.

The question you'll ask four times today is has the box gone past a wall? And when the answer is yes, you flip its direction by sticking a minus in front of it: vx = -vx.

A box travelling right at 240 becomes a box travelling left at 240. Same speed, opposite way. That's a bounce.

Stuck?

Hint 1 — which thing do I change?

Where the box is: x and y. Which way it's going: vx and vy.

When it hits a wall, where it is is fine. It's the direction that's wrong. So which pair do you change?

And since x and vx are the across-the-screen pair, hitting a left or right wall only changes vx. Up and down doesn't come into it.

Hint 2 — how do I reverse a direction?
Put a minus in front of it. vx = -vx means "vx becomes the negative of whatever it was". If it was 240 it's now −240. If it was −240 it's now 240, because minus a minus is a plus. That one line handles both walls.
Hint 3 — the right wall keeps going wrong
x is the left edge of the box. If you check if x > WIDTH, the box has to travel its own width past the wall before anything happens — so it sinks into the edge before bouncing. You want its right edge, which is x + BOX_SIZE.
Show me a finished version 
def update(x, y, vx, vy, dt):
    x = x + vx * dt
    y = y + vy * dt

    if x < 0:
        vx = -vx
    if x + BOX_SIZE > WIDTH:
        vx = -vx
    if y < 0:
        vy = -vy
    if y + BOX_SIZE > HEIGHT:
        vy = -vy

    return x, y, vx, vy

Challenge

Make it change colour every time it hits a wall. The real screensaver did exactly this.

You'll want a list of colours and a number that remembers which one you're on. When a bounce happens, move to the next colour — and when you run off the end of the list, go back to the start. You already know how to make a list from Session 8.

Then leave it running. The famous thing about this screensaver is that people waited years to see it land exactly in a corner. Nobody's checking yours, so it's on you to be honest about whether you actually saw it.

How it could break

NameError: name 'vx' is not defined update doesn't know about vx yet. Check the def line has all five slots: def update(x, y, vx, vy, dt):
The box shivers against the wall instead of leaving It's still past the wall, so you flip it again on the very next frame, and again, and again. Fix: when it hits, also put it back on the edge — x = 0 for the left wall.
It bounces off the sides but sails straight out of the top You copied the x lines and missed one when changing them to y. Easiest bug in the world to make and the hardest to spot — read the four checks out loud and you'll find it.
It gets stuck in a corner and jitters Two walls are both flipping it every frame and fighting each other. Same fix as the shivering one: push it back to the edge after you flip.
IndentationError: expected an indented block The line after an if ...: has to be pushed further in than the if itself. That indent is how Python knows which lines the question controls.
SyntaxError: invalid syntax Nine times out of ten it's a missing colon at the end of the if line.

Stop while it still runs.
