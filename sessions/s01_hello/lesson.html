What you're making

A program that prints words at you. No window yet, no graphics — just text in a black box.

Everything you write after this is made of lines like these.

New this session

A program is a list of instructions, done in order, from the top. Python reads line 1, does it, reads line 2, does it, and keeps going until it runs out. It never skips ahead and never guesses what you meant.

print(…) puts something on the screen. Whatever you put inside the brackets is what comes out.

Words need quote marks around them: print("Hello"). Numbers don't: print(42). That difference matters more than it looks, and the last two lines of the file show you why.

Stuck?

Hint 1 — where do I actually type?
Open main.py in your editor — it's just text. Change it, save it with Ctrl+S, then run it again. Nothing you type has any effect until you save.
Hint 2 — why do some things need quotes?

Quotes mean "this is words, don't try to understand it". No quotes means "this is a value, work it out".

So print(7 * 6) does the sum and prints 42. print("7 * 6") prints the three characters 7 * 6 because you asked for the words, not the answer.

A name like Hello without quotes would send Python hunting for something called Hello, find nothing, and complain.

How it could break

run.bat : The term 'run.bat' is not recognized… PowerShell won't run a program from the folder you're standing in unless you point straight at it. Put .\ on the front: .\run.bat 1.
SyntaxError: unterminated string literal A quote mark got opened and never closed. Every " needs a partner.
SyntaxError: '(' was never closed Same thing with brackets. Python read to the end of the file still waiting for the ).
NameError: name 'Hello' is not defined You wrote print(Hello) without quotes, so Python went looking for something called Hello. Put the quotes back.
Nothing comes out at all Either the file wasn't saved, or every line has a # in front of it.
