Your First Window

Every game you've ever played started as an empty rectangle. Here's yours.

What you're making

A window. It'll be the size you choose, the colour you choose, with your name in the title bar. Nothing will happen inside it yet — that's Session 7.

Sounds small. It isn't — every game you go on to make gets painted inside a rectangle like this one.

New this session

A program that doesn't loop is over instantly. Python reads your file top to bottom, does what it says, and stops. If that's all we did, the window would flash up and vanish in about a thousandth of a second.

So we put the last part in a while loop — "keep doing this over and over until I say stop". That loop runs about 60 times a second, forever, and the window stays.

Every game ever made works this way. It's called the game loop, and you already have one.

Turn the knobs

Change a number, run it again. You can't break anything here — and if you do, we can put it back.

(800, 450)Width and height in pixels. Try (200, 700) for a tall skinny window. Try (1, 1) and see what your computer does about it.
(20, 22, 34)How much red, green and blue light to mix, in that order, each from 0 (off) to 255 (full brightness). (0, 0, 0) is black — all three off. (255, 255, 255) is white — all three flat out. (255, 0, 255) is a bright pink that nobody should use on purpose.
clock.tick(60)The speed limiter, last line inside the loop. Delete it and the loop runs about ten thousand times a second instead of sixty, repainting the same colour as fast as it possibly can. Nothing looks any different — but listen to your computer's fan. Then put it back.
"Session 6"The text in the title bar. Anything inside the quotes works.

Stuck?

Hint 1 — where do I actually type?
Right-click main.py and open it with VS Code, or with Notepad if that's easier for now. It's just text. Change it, save it (Ctrl+S), then run it again. Nothing happens until you save.
Hint 2 — what are the three colour numbers?

Screens don't have paint. Every colour you have ever seen on one is made by mixing three tiny lights: red, green and blue. That's what people mean by RGB.

Each number says how bright that one light is, from 0 (completely off) to 255 (as bright as it goes). They're always written in that order, so (255, 0, 0) is pure red, (0, 255, 0) is pure green, and (0, 0, 255) is pure blue.

Mixing light doesn't work like mixing paint, which catches people out. Red and green together — (255, 255, 0) — gives you yellow. Try it and see.

Hint 3 — which brackets are which?
Round brackets ( ) group things together. The colour needs its own set of brackets inside the fill brackets, which is why fill((20, 22, 34)) looks like it has too many. It doesn't — count them.
Show me a finished version

The comments are stripped out here to keep it short. Leave the ones in your own file alone — they're there to remind you what each line does.

# Session 6 - Your First Window

import pygame

pygame.init()

screen = pygame.display.set_mode((600, 600))
pygame.display.set_caption("Made by me")
clock = pygame.time.Clock()

running = True
while running:

    for event in pygame.event.get():
        if event.type == pygame.QUIT:
            running = False

    screen.fill((255, 40, 40))

    pygame.display.flip()
    clock.tick(60)

pygame.quit()

Challenge

Match a colour exactly. Pick any colour from a game you like — a Geometry Dash background, anything — and get your window to be that precise colour.

To find its three numbers, search the web for “online colour picker”. Loads of free ones will come up. They give you a rainbow to drag around, and show you the red, green and blue values for whatever colour you land on. Copy those three numbers straight into your screen.fill(…).

If a colour picker gives you something like #3DE1E1 instead, that's the same thing written differently — look for the box marked RGB and use those numbers instead.

How it could break

ModuleNotFoundError: No module named 'pygame' Either setup.bat hasn't been run yet, or you started the file by double-clicking it instead of using .\run.bat 6. Use the bat file — it knows where the right Python lives.
run.bat : The term 'run.bat' is not recognized… PowerShell refuses to run a program from the folder you're standing in unless you point straight at it. Put .\ on the front: .\run.bat 6. That form works in every Windows terminal, so it's the one worth getting into your fingers.
The window says "Not Responding" and won't close The for event block got deleted or broken. Windows needs the program to keep checking its messages, and that block is the checking. Put it back.
The window flashes up and disappears Something went wrong with the while loop. Check that running = True is above it and nothing set it to False too early.
SyntaxError: unexpected EOF while parsing A bracket got opened and never closed. Python read all the way to the end of the file still waiting for it.
Nothing at all happens Check the black window that run.bat opens — the error message is in there, and it's usually more helpful than it looks.

Stop while it still runs.
